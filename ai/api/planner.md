# Planner Integration Contract

Defines the structure of plans and tool selections.

## Contract Elements

### `ExecutionPlan`
A plan generated by the Intent Planner containing structured intents and list of tool executions.

```json
{
  "intent": "retrieve_user_schedule",
  "confidence": 0.95,
  "steps": [
    {
      "step_id": "retrieve_calendar",
      "tool_name": "calendar.get_events",
      "args": {
        "time_min": "2026-07-18T00:00:00Z",
        "time_max": "2026-07-18T23:59:59Z"
      }
    }
  ]
}
```

## Step Executions

1. The Planner classifies intent.
2. The Planner determines necessary steps and associated tools.
3. Steps are validated against the available tools in the registry before orchestrator execution.
